// Arquitectura & Caso de Estudio

Distri Muebles — Plataforma ERP Web

01. Resumen de la Reconstrucción Web

Modernización y migración arquitectónica integral de un sistema ERP comercial originalmente construido en Java Swing/NetBeans y MySQL hacia una plataforma Web moderna, reactiva y escalable. Diseñada bajo un monorepo administrado con Turborepo y pnpm workspaces, garantizando separación estricta de responsabilidades, alta mantenibilidad y cumplimiento de reglas fiscales y financieras reales (multi-tasa IVA 10%, 5% y exento).

02. Arquitectura de 4 Capas

◆ Frontend Web Moderno

Desarrollado con Next.js 16 (App Router), React 19 y TypeScript. Interfaz administrativa fluida con Tailwind CSS, tablas dinámicas avanzadas con TanStack Table y validación de formularios con Zod.

Next.js · React 19 · Tailwind CSS · TanStack
◆ Backend & API REST

Construido con NestJS siguiendo principios de Clean Architecture y Domain-Driven Design (DDD). Documentación automática con OpenAPI / Swagger, autenticación con Argon2 y sesiones seguras.

NestJS · TypeScript · OpenAPI · Argon2
◆ Base de Datos & Dominio

PostgreSQL 18 con Prisma ORM. Aislamiento lógico multiempresa y multisucursal mediante empresa_id obligatorio. Precisión financiera con tipos numeric y gestión multimoneda con cotizaciones históricas.

PostgreSQL 18 · Prisma ORM · Multiempresa
◆ Procesos Asíncronos & Reportes

Microservicio trabajador en segundo plano con Redis para tareas pesadas. Emisión de facturas y comprobantes en PDF con Playwright y exportación de reportes analíticos a planillas Excel con ExcelJS.

Redis · Worker · Playwright PDF · ExcelJS
